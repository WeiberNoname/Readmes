# W DoBark

*Formerly Pup Pop.* The name changed in v3.0.0; saves and settings from earlier versions carry on (the project, its folders and `%LOCALAPPDATA%\PupPop` keep the old internal name). New postcards go to `Pictures\W DoBark`; earlier ones stay in `Pictures\Pup Pop`.

A musical match-three game in Unreal Engine 5.7 with six 3D toy puppies in the parks (corgi, beagle, poodle, husky, pug and dalmatian) and five more on a hidden treasure board (golden retriever, samoyed, dachshund, French bulldog and border collie).

The board is a wooden toy stand set in a 3D park, seen through a tilted camera with a gentle tilt-shift blur. Each of the seven zones has its own time of day and weather: morning in Clover Meadow, golden hour in Blossom Gardens, sunset at Sunset Shores, a lamp-lit night in Starlight Park, falling leaves in the Autumn Orchard, drizzle in the Rainy Harbor and snowfall in the Snowy Pines. The park has curved grass tufts, clover patches with buttercups, and a little flower bed under the companion pup. The puppies are sculpted vinyl-toy models with glossy eyes. They blink, tilt their heads toward what you touch, make happy ^^ faces after a good match, look surprised when something goes off next to them, and doze off with little Zs if you leave them alone.

## Download

The game ships as one Windows file, `W-DoBark-v3.2.0.exe` (about 265 MB, Windows 10 or 11). It is **not stored in this repository**: `Scripts/MakeApp.ps1` builds it into `Dist` on the PC that makes the release, and from there it is passed on by hand (a USB stick, a shared drive, a chat or cloud-storage link).

`Scripts/Release.ps1` can publish it as a GitHub Release instead, on a fast enough connection. That gives each version a release page, and one link that always points at the newest build (`https://github.com/WeiberNoname/W-DoBark-Beta-End-Handled-By-Claude--/releases/latest/download/W-DoBark-Windows.exe`). It needs the GitHub CLI (`winget install GitHub.cli`, then `gh auth login` once). The repository is private, so its releases are too; only accounts with access can download them.

## Android (first version)

`Dist/Android/W-DoBark-v3.2.0-android-arm64.apk` is the Android build (64-bit ARM phones, Android 8.0 or newer, landscape). Copy it to the phone, tap it and allow "install unknown apps". Taps work as clicks and swipes as drags; the on-screen joysticks are off, and phones start with Large text.

To build it: install Android support for Unreal 5.7 in the Epic Games Launcher (Options, Target Platforms), the Android SDK Command-line Tools and NDK 27.2 in Android Studio, run `Engine/Extras/Android/SetupAndroid.bat`, and set `JAVA_HOME` to a JDK 21 (Android Studio's own Java 25 is too new for Unreal's Gradle). Then run `RunUAT BuildCookRun -platform=Android -cookflavor=ASTC -build -cook -stage -pak -package -archive`. Touch input is compiled only for Android and iOS, so the Windows game is unchanged.

## Play

Double-click **`Dist/W-DoBark-v3.2.0.exe`**. It is the whole game in one file that you can copy to any Windows 10 or 11 PC. It is built locally (see Download) and is not part of a clone. The first launch unpacks it to `%LOCALAPPDATA%\PupPop\App` in a few seconds; later launches start straight away. Saves go to `%LOCALAPPDATA%\PupPop\Saved`.

To test it hands-free, run `Dist\W-DoBark-v3.2.0.exe --selftest`. A bot plays eight parks, at least one in every zone, while you watch. After every move it checks that the screen matches the rules, and it ends on a PASS or FAIL card. The result is also written to `%LOCALAPPDATA%\PupPop\Saved\SelfTest.txt` and screenshots to `Saved\Verify` next to it. Add `-PupQuick` for three levels, or `--wait` to have the command return the game's exit code: 0 for PASS, 1 for FAIL.

**Play W DoBark.cmd** starts the newest single-file app in `Dist`, whatever its version. If there is none (or only a Git LFS pointer), it falls back to the packaged build in `Builds/Shipping/Windows`, then the development build in `Builds/Windows`, and says what to run if nothing has been built. Keep a `Builds` folder together when copying it.

Pick a park on the world map, read its goals, then swap neighbouring pups (click-click or drag) to line up three or more of the same breed.

## Readability and Chinese language support (v3.2.0)

The existing board-side panels are now 14% smaller in width and height, leaving more room around the puppies. The original controls remain, with matching smaller click targets and the bottom buttons kept at the bottom of the screen.

Open **Settings** on the map, or **Full Settings & Keys Reference** from Pause:

- **Language:** English, 繁體中文 (Traditional Chinese), or 简体中文 (Simplified Chinese). Menus, goals, all 42 park/treasure names, tutorials, shop descriptions and Puppy Home are translated.
- **Text size:** Small (90%), Standard (100%), or Large (115%). Fixed-width labels fit their containers; paragraphs wrap Chinese text and explicit line breaks.
- **Keyboard:** Left/Right changes language and Up/Down changes text size while Settings is open. Enter or Esc closes Settings.

Changes apply immediately and are saved independently of progress. Existing saves keep English and Standard text. Chinese dog names are supported. Both regional Noto Sans CJK fonts ship with the game, including fallback glyphs for the Chinese language buttons in English mode.

**A hard gate in every park but the first.** The first park keeps its easy tutorial gate. Every other park hides its gate in the hardest place the key can still reach:
- **The hardest column.** The key starts at the very top of its column and the gate sits at its foot, so every cell of the column lies between them. Columns with hedges and kennels in the way, and edge columns, are preferred. The key never slides, so its neighbouring columns must have no holes: every cell it leaves still refills.
- **The key fades.** A hard gate's golden key shines for only a few moves (4 to 9, set per park). A badge on the key counts them down, turning coral for the last two, and the pill above the board says how many are left. Tools and the Pack Howl don't use them up, so a Paw Tap under the key is a good way to hurry it. When the moves run out the key fades in a puff of pale gold with a soft falling chime, and the gate goes quiet for the rest of that game. The next game brings a fresh key.
- **Overgrown gates.** In some parks (Harvest moon, Lighthouse, Storm watch, Northern lights) thick hedge also grows right over the gate. Those guard hedges block the key like any hedge, but they never count toward a "trim the hedges" goal.
- **Bones and gates together.** Bones used to rule gates out; now a bone in the gate's column goes home through the gate. No bone falls in above the key, where it could get stuck behind it.
- **Never impossible.** For every park and 40 random deals, the rules self-test checks that tapping whatever lies under the key, over and over, always brings it into the gate.
- **Tuned with the bots.** The sharp bot, which always goes after the key, opens about a third of the gates in the first parks and about one in ten by park 35. The casual bot opens fewer. Each park's key time was chosen by measuring it. The easy tutorial gate still opens in almost every first-park game.

**A treasure burrow for every zone.** Each zone's gates lead to their own burrow in the Hidden Hollow, all with the five rare dogs and 5 free moves: a clover, a heart, a shell, a star, an apple, a sailboat and a snowflake.

## The secret gate and its treasure bonus (v2.8.0)

The first park, *First tail wags*, hides a secret. A little garden gate stands in the bottom row of the board: a stone arch with a flowering vine, a teal door, a gold keyhole plate that glows, and a paw emblem. Three pups straight above it floats a **golden key** with a dog-bone handle and a mint gem.

- **How they meet.** The key cannot be swapped, tapped, replaced or blasted: it only ever falls, straight down its own column. Clear the three pups beneath it and it drops onto the gate, flies over it into the keyhole, turns, and the door swings open with warm light pouring out (+1,500). The keyhole glows and the key wears a soft golden halo, hovering the key or gate explains them, and a small pill at the top of the board tracks the secret. (v2.8.1 removed the dotted trail that used to link them: finding the way is part of the secret.)
- **Where they go.** This tutorial gate is always in the bottom row near the middle of the board, in a column that is plain all the way up to the key (no holes, mud, hedges, kennels or bones), with the key exactly three pups above it. The rules self-test checks this for every seed. The other 34 parks hide theirs in the hardest place instead (see above).
- **A one-time deal, inside the game.** The moment the key opens the gate, while you are still playing, the camera flies through the doorway into the moonlit Hidden Hollow onto the zone's **treasure burrow**: 5 free moves on a board of five rare dogs. The park waits exactly as it was, with its own moves.
  - **Your score keeps growing.** Every point you make on the treasure board goes onto the park's score, and the star bar keeps filling while you play there. A panel counts the treasure points, and the Pack Howl meter comes along both ways. The round has no goals and no finale: when the free moves run out, you fly back through the Hollow's gate to finish the park.
  - **Five times the coins.** Win the park after the treasure and every part of its reward is multiplied by five. For the first park that is 125 coins for a win, 250 more for the first clear and 75 for each new star (600 for a first three-star clear), where a normal park win pays 25 to 120 and shop items cost 40 to 100. The results show "+600 coins (x5 treasure!)" and how many of the points came from the treasure.
  - **Once a game, never on the map.** Nothing is saved and nothing waits on the map: the chance comes only while the park is being played, once per game. After the trip the gate stays open but dark. A new game of the park hides a fresh key. A gate opened by the finale's fireworks, after the park is already won, comes too late.
- **Balance.** The bots open the gate in 100% (sharp) and 95% (casual) of first-park games. The 5 free moves add about 9,000 points: the first park's average goes from 1.73 to 2.60 stars (sharp) and from 1.30 to 2.02 (casual). With 8 free moves it was 2.90 and 2.40, which made three stars nearly automatic, so the round is kept short.

### Five rare dogs, easy to tell apart

Only the treasure board has these five, and it has only them:

- *Golden retriever*: deep red-gold with a cream feathered chest, long soft ears with a fringe and a plume tail; moves and sings like the dalmatian.
- *Samoyed*: a white cloud with a big ruff, fluffy cheeks around its smile, little pink-lined ears and a curled plume; moves and sings like the husky.
- *Dachshund*: a red chestnut sausage dog standing side-on, long and low, with a long muzzle, long drop ears and a thin tail; moves and sings like the beagle.
- *French bulldog*: steel blue with big upright bat ears (pink inside, tilted to face the camera), a navy flat bulldog muzzle and a stub tail; moves and sings like the pug.
- *Border collie*: black with a white blaze, muzzle, collar ruff, chest, paws and tail tip, and pointed ears; moves and sings like the husky.

Each has its own collar tag (sun, snowflake, sausage, moon, cloud) and face icon, and about 8% of the pups that fall in are treasure mixes, such as a golden-collie.

The colours were chosen so older players can tell every pair apart. There is one light dog (samoyed), one dark dog (collie), and three mid tones that differ in both hue and brightness. The treasure board is lit by warm white lantern light; v2.7.0's teal moonlight washed the coats toward the same pale blue-grey. `Scripts/check_contrast.py` measures the coats on the game's own screenshot. It takes the dominant colour of a small disc on every dog's head (on its back for the side-on dachshund), so eyes, ears and the collie's white blaze don't count. Then for each pair of breeds it computes the CIEDE2000 colour difference (about 20 reads as clearly different) and the brightness ratio. It does this for normal vision, the three kinds of colour blindness, and an older eye (a yellowed lens plus a quarter of the contrast lost). `Verify.ps1 -Secret` fails when any pair gets too close. On the self-test screenshots the closest pair went from 11.9 to 23.1 for normal vision and from 9.7 to 16.8 for an older eye (v2.9.0's measurement).

## For dog people (v2.5.0)

- **Real dog nearby: calm sounds.** Many players have a dog on the sofa next to them. Turn this on in Pause or Settings and every bark, yip, howl, whimper, squeaky toy, bouncing ball, low boom and party horn becomes a soft tone: the breeds hum their notes on the marimba, the Pack Howl becomes a warm chord, and the Squeaky Ball bloops at about 730 Hz instead of squeaking at 3 kHz. The music is unchanged. The setting is saved.
- **Mixed-breed pups.** In Starlight Park (levels 16 to 20) about 6% of the pups that fall in are mixes, like a pug-poodle or a corgi-husky. A mix has one parent's body and the other's head and ears, wears a badge with both faces, and matches with **either** breed, so it can join a line of corgis and a line of huskies at once. Popping it counts for both breeds' goals, a Squeaky Ball swapped with it pops both breeds, and if it becomes a special it keeps the breed it matched as. Hover or select one to read which breeds it matches. Starting boards stay purebred.
- **Tricks.** In Puppy Home, select a dog and press **T** (or **Trick**) to go through its tricks: chase its tail, roll over for a belly rub, play bow, sit pretty, and speak. Once the cozy cloud bed is in the garden, the sixth trick is a nap: the dog hops into the bed and dozes with little Zs. Pet it (**P**) to wake it up.
- **Postcards.** Press **C** (or **Postcard**) in Puppy Home. The pack strikes a happy pose, and a framed picture with their names and the date is saved to `Pictures\W DoBark`. Press **O** to open that folder.

## Puppy Home (v2.4.0)

Press **F** from the map or results to visit your garden. Biscuit the Corgi is your first permanent friend. Adopt more dogs for free after clearing every park through their milestone: **Beagle 3, Poodle 5, Husky 10, Pug 15, Dalmatian 20**. Existing progress counts. The map's home button announces when a pup is ready to adopt.

Select a dog to read its personality, give it a name (up to 16 letters, spaces, apostrophes or hyphens), pet it, or choose it as your companion. Your companion's actual breed and saved name appear beside the puzzle board, where it cheers for your matches. Companions are cosmetic; choose the dog you love. Adopted dogs stay permanently and do not use or grant shop dog tokens.

Spend earned stars on three permanent decorations: **Cozy cloud bed (3), Buttercup garden (5), Rainbow agility hoop (8)**. Purchases need confirmation. Store and place owned decorations freely. Your spendable balance is total earned stars minus the cost of owned decorations; level star ratings and unlocks stay intact. Replaying the same rating cannot replenish spent stars; earning a better rating gives the difference. Names, adoptions, companion choice, ownership and placement are saved. Failed saves roll back changes.

In the home, use **arrows** to browse: the dogs stand in a 3 x 2 grid and the decorations form a column on the right, so left and right move between them. Use **Enter** to adopt/select/build, **N** to rename, **P** to pet, **T** for a trick, **C** for a postcard, **M** to toggle music, and **Esc** to cancel or return to the map. The selected dog or decoration and its buttons sit in the bar below the garden, so the cottage, decorations and puppies stay in full view. The name editor supports normal typing, paste, Enter to save, Escape to cancel, and Tab navigation. The home opens between levels so visiting never abandons an active board.

## Pup Supply Shop (v2.3.0)

Press **S** or choose **Dogs & shop** to browse ten products. Coins and owned items are saved locally alongside progress. Both new and existing saves receive a one-time welcome gift of **200 coins and one of each assist tool**. Every win earns 25 coins, first clears add 50, and each newly earned star adds 15. Replaying a completed park earns the base reward again; first-clear and star bonuses only apply once.

| Product | Coins per copy | Effect |
| --- | ---: | --- |
| Paw Tap | 40 | Clear a pup or damage one hedge/kennel layer. Tapped specials activate. Bones are protected. |
| Magic Leash | 60 | Swap two adjacent unlocked pieces without spending a move, even without a match. |
| Treat Shuffle | 70 | Rearrange movable pups into a settled board with a legal move. Keeps breed/special identities, bones and blockers. |
| Second Wind | 100 | Add 5 moves, once per attempt. Available during play or after running out of moves. |
| Corgi, Beagle, Poodle, Husky, Pug, Dalmatian | 75 each | One consumable dog token replaces an ordinary pup or an entire hedge with the chosen breed. Any resulting matches resolve immediately. |

All six dogs are available immediately, including breeds that do not normally spawn in the current level. Replacement cannot overwrite bones, kennels, specials or a pup of the same breed. Replacing a hedge advances the hedge goal; replacing a pup does not count as collecting that old pup. Mud stays until cleared normally. Items never cost a move.

Every product is shown as a photo of its real 3D model: a small studio above the park (`Source/PupPop/Game/PupStudio.cpp`) photographs the board puppies and the tool models (a toy paw, a leash, a treat bowl and a water bowl) with their own lights when the game starts, so the shop shows exactly what appears on the board. Select a product, choose **Buy**, then confirm its price. **Use owned** opens a target preview. Choose a tile (two neighbours for Magic Leash), then confirm; **Esc** cancels without spending anything. Arrows browse the shop or move the board cursor, Space picks a target, Enter confirms, B starts a purchase and U uses the selected product. The bag holds up to 99 copies of each item. Insufficient coins, invalid targets, failed shuffles and failed saves do not consume inventory. Items are saved when bought or used; restarting a park does not refund used items.

## Match basics

| Match | Makes | When it goes off |
| --- | --- | --- |
| 4 in a line | **Zoomies Pup** (bandana, goggles) | Dashes along the row or column you swiped |
| L or T shape | **Bubble Bath Pup** (rubber duck) | Splashes a 3x3 area, then splashes again after things fall |
| 5 in a line | **Squeaky Ball** | Swap it with any pup to pop that whole breed |
| 2x2 square | **Fetch Pup** (tennis ball) | Runs off to the trickiest spot: kennels, hedges, mud, pups under bones |

Swapping two specials together combos them: Zoomies + Zoomies clears a cross, Zoomies + Bubble a three-wide cross, Bubble + Bubble a 5x5 area, Fetch carries the other special to its target, Ball + any special turns that whole breed into the special, and two Balls clear the park.

Levels have limited moves, 1-3 stars, and goals: score, pop a number of a breed, wash away mud (1 or 2 layers), trim hedges (1 or 2 layers), free pups locked in kennels, and bring bones down to the doghouses at the bottom. Boards can have holes, and pups slide diagonally around blockers. Stuck boards shuffle themselves. When the goals are done, **Pawty Time** turns every leftover move into a Zoomies pup and sets off every special on the board.

## What is new for the puppies

- **The board is an instrument.** The music is a 120 BPM loop in C major. Every pop plays a note on the chord that is playing, cascades climb that chord, and the breeds you matched sing along in their own voices (a corgi yip, a beagle's aroo, a husky's awoo...). Picking up a pup makes it sing its note.
- **Swap on the beat.** The pups bounce, the tails wag and four paws on the right light up with the beat. A swap on the beat scores 50% more.
- **Swaps hop.** A swapped pup hops over its neighbour (about 24 cm high) while the other slides underneath, with a little squash on landing.
- **Blasts push pups.** When a Bubble Bath or Zoomies goes off, nearby pups lean away from it and their ears blow back.
- **Idle dancing.** Waiting pups shift their weight in time with the music.
- **Eyes follow you.** Pups glance toward the cursor and what you touch, their pupils widen during combos, and idle pups doze off, breathing slowly and thumping their tails.
- **Panting and jingling.** Happy pups pant, and collar tags swing as they move.
- **Breed personalities.**
  - *Corgi*: hip wiggles, head bobs, twitching fox ears and a bobtail shimmy.
  - *Beagle*: nose dips, long swinging ears and a proud upright tail.
  - *Poodle*: a lifted head, bouncing pom-pom ears and a twirl when happy.
  - *Husky*: little howls, swivelling ears and a sweeping plume tail.
  - *Pug*: quick head tilts, a chubby wobble, snorts and a springy curled tail.
  - *Dalmatian*: an athletic stance, floppy ears and a long whip tail.
- **Pack Howl.** Every pop fills a meter. When it glows, press W: the mascot howls, a ring of sound rolls across the park, and four pups become specials without costing a move.
- **Adaptive music.** Four stems (bed, groove, lead, sparkle) mix live: the groove and sparkle rise with combos, the band gets tense on the last five moves, Pawty Time brings everything in, and pausing muffles it.
- **Sound you can see.** Music notes float up from matches, zoomies leave glowing paw prints, the howl and the beat pulse as rings of light.
- **Paw cursor.** The pointer is a puppy paw that wiggles over buttons and dogs, squashes with a ripple when you click, and leaves a short trail of sparkles.
- **Clearer board and special badges (v2.2.1).** More space between pups and cushions, quieter bubbles and narrower blast beams keep faces visible. Small badges identify row/column Zoomies, Bubble Bath (with a second-splash marker), Fetch and Squeaky Ball. Hover or select a special for a short explanation. Outlined corners mark selection, keyboard focus and hints; celebrations appear below the goals and beat feedback stays in its meter.
- **Controls in the game.** The Pause menu and Settings show every key.
- **Easy to tell apart.** Each breed has its own coat colour and brightness: orange corgi, brown beagle, pink poodle, slate-blue husky, black pug with a grey muzzle (v2.4.0; it used to be cream and looked too much like the white dalmatian), and white dalmatian. The collar tags carry a shape per breed (star, bone, heart, diamond, crown, clover), which Settings can enlarge. Screen shake can be turned off, and the whole game can be played with the keyboard.

Progress, stars, best scores and settings are saved locally (`Saved/SaveGames`).

The rules report everything they do as steps of events (swap, clear, upgrade, activate, tile, move, spawn, deliver). The board view only animates those events, and the rules tests replay the same events to prove the view can never lose track of a piece.

## Build and test

- `powershell -ExecutionPolicy Bypass -File Scripts/TestRules.ps1` runs in seconds with no Unreal: the rules self test, a check that every level starts full, settled and playable across 40 seeds, and a sharp and a casual bot playing every level to report win rates and stars. When a bot opens a secret gate it plays the treasure bonus round too, and the harness reports what that round adds.
- `powershell -ExecutionPolicy Bypass -File Scripts/Build.ps1` runs the rules tests, builds the models (Blender 4.4), draws the glyph atlas (Python with Pillow), regenerates the sounds (Python with numpy), compiles, builds the content and packages `Builds/Windows`. Pass `-Engine` or `-Blender` for other install paths, `-SkipPackage` to stop before packaging.
- `powershell -ExecutionPolicy Bypass -File Scripts/MakeApp.ps1` makes the single-file `Dist/W-DoBark-v<version>.exe` from the Shipping build in `Builds/Shipping/Windows`, packaging that build first if it is missing (`-Package` to always repackage). It compiles the small launcher in `Tools/Launcher` and appends the game to it as a zip (`Scripts/pack_app.py`). The version comes from `ProjectVersion` in `Config/DefaultGame.ini` and is also written into the exe's file details; older versions in `Dist` are removed. A new build unpacks to a new folder on the player's PC and removes the old one.
- Store art comes from the game itself. `-PupNoHud` renders the 3D scene without the interface and `-PupNoCursor` hides the paw pointer, for staged pictures. `-PupKeyArt` poses the eleven dogs like a class photo on a wooden stand in the meadow (three rows in a portrait window), then photographs them close, near and far, in front of the first park's board, and in a close-up of Biscuit the corgi for the icon. The pictures go to `Saved/Verify`. `Store/Steam/make_capsules.py` and `make_icon.py` turn those renders into Steam's capsules, library images and icons; `Store/Steam/Steam store page.txt` lists every file and says where it goes.
- `blender -b --factory-startup --python Scripts/models/preview.py` renders the assembled puppies and props to `Saved/Models/Preview*.png` for a quick look without Unreal.
- `powershell -ExecutionPolicy Bypass -File Scripts/Verify.ps1` plays eight parks (one or more in every zone, the world map's glow, scrolling and walk, the Map button) unattended in the packaged game, checks after every move that what is on screen matches the rules, and saves screenshots to `Builds/Windows/PupPop/Saved/Verify`. Add `-Editor` to run it through the editor instead, `-Quick` to play three levels, `-Secret` to open the secret gate in the first park and follow the treasure bonus round (the trip through the gate, the free moves, the points carried back to the park, the x5 reward, once a game) and measure the treasure dogs' colour contrast with `Scripts/check_contrast.py`, or `-PuppyHome` to test adoption, naming, companion selection, decorations, tricks, naps, calm sounds, postcards, failed-save rollback and home persistence; use `-Shop` to test purchases, inventory serialization, legacy-save migration, cancellation, every tool and dog token, move recovery and reward deduplication.

### Level file

Board rows use one character per cell: `.` plain, `x` hole, `m` mud, `M` deep mud, `h` hedge, `H` thick hedge, `k` kennel, `K` kennel on mud, `b` a bone. Goal types are `score` (with `target`), `collect` (with `breed` and `target`), `mud`, `rescue`, `hedges` and `bones` (with `target`). `mutts` (0 to 50, default 0) is the percentage of new pups that fall in as mixed breeds; levels without it play exactly as before. `"gate": "easy"` hides the tutorial gate; `"gate": N` (3 to 30) hides a hard gate in the hardest place its key can reach, the key shining for N moves (`true` means 8), and `"gateHedge"` (0 to 4) overgrows it with that many layers of guard hedge. Gates and bones can share a park. `"secret": true` makes a treasure board behind the gates: it is never on the park map and is only played as the one-time bonus round when a gate opens, and `"park"` names the zone whose gates lead to it. Its `moves` are the free moves; it needs no goals and cannot hide a gate of its own. On it, `"coins"` (1 to 20) is how many times the coins a park pays when won after its bonus round. `"dogs"` lists the 3 to 6 breeds that fall on a board, by name (`corgi`, `beagle`, `poodle`, `husky`, `pug`, `dalmatian`, `golden`, `samoyed`, `dachshund`, `frenchie`, `collie`); without it a level uses the first `breeds` park dogs as before. Park dog tokens from the shop only fit boards of park dogs. Every cell must be reachable by falling or sliding pups; `Scripts/TestRules.ps1` reports any that are not.
